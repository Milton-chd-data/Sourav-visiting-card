# Sourav Digital Visiting Card

A responsive, static digital business card suitable for GitHub Pages.

## Before publishing
Open `index.html` and update the `profile` object near the bottom:
- `name`
- `phone` (international format, e.g. `+919876543210`)
- `email`
- `address`
- `instagram`, `facebook`, `linkedin` (full profile URLs; leave empty to hide)

Everything in this public repository and published page can be seen by anyone. Only add contact information you are comfortable sharing publicly. Do not add passwords, private keys, or private documents.

## Publish with GitHub Pages
1. Open repository Settings.
2. Choose Pages.
3. Under Build and deployment, select Deploy from a branch.
4. Select branch `main` and folder `/ (root)`, then Save.
5. Wait for the published URL shown in Pages settings.

This starter template does not modify any other repository or your Milton Document Manager.
